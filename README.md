# devtools

浏览器中的个人工具箱。使用静态 HTTP 服务运行，例如在项目目录执行 `python -m http.server 8000`，再打开 `http://localhost:8000`。

## PDF / Word 文件转换

在侧边栏选择「PDF / Word 文件转换」，选择方向和文件，点击转换，再下载结果。

- **PDF → Word（.docx）**：可选择提取可编辑文字（按原 PDF 分页，不还原图片、表格或多栏布局），或将每页作为图片插入 Word 以保留外观。
- **Word（.docx）→ PDF**：在浏览器排版后生成图片式 PDF，尽量保留图片、表格及页眉页脚。分页根据实际文字行和页面像素选择空白断点，尽量保持表格行、图片完整，避免文字从中间被切开。超高表格行可在文字行之间拆分；找不到安全空隙时会提示调整文档。导出文字不可搜索或复制，复杂排版、字体和分页可能与 Microsoft Word 不同。
- 文件在浏览器本地处理，不上传服务器。转换时从 jsDelivr 按需加载固定版本的开源组件及 PDF 字体数据，需要网络；文档渲染隔离在禁止脚本和外部资源请求的沙箱中。
- 单个文件最大 30 MB，最多转换 100 页。超长 Word 分节需要先插入分页符。暂不支持旧版 `.doc`、加密 PDF 或 OCR；扫描 PDF 可使用「保留外观」模式。

转换组件：PDF.js 6.4.299、docx 9.15.0、JSZip 3.10.2、docx-preview 0.4.1、html2canvas 1.4.1、jsPDF 4.2.1。无须后端或构建步骤。

## 视频转 GIF：固定区域裁剪

选择视频后，开启「只转换选定区域」，输入原视频像素下的宽、高和 X/Y 坐标。拖动蓝框改变位置，宽高保持固定；也可以用方向键微调（Shift 每次移动 10 px）。支持居中、1:1、16:9、9:16 和完整画面预设。

「GIF 宽度」控制最终缩放尺寸，高度随选区比例计算，界面会显示输出尺寸。时间范围和帧率仍可调整；关闭区域裁剪即可导出完整画面。生成期间会锁定参数，防止选区中途变化；过大的输出尺寸或帧数会提示缩小参数。

## 回归检查

使用 Node.js 运行 `node --test tests/conversion.test.mjs`，验证分页连续性、文字行和表格行边界，以及裁剪尺寸和坐标约束。
